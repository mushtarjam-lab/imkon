IMKON — ta'lim hamma uchun
==========================

Bu IMKON loyihasining boshlang‘ich ishlaydigan veb-prototipi.

ISHGA TUSHIRISH:
1. ZIP faylni kompyuterga yuklab oling va arxivdan chiqaring.
2. IMKON_platforma papkasini oching.
3. index.html faylini ikki marta bosing.
4. Sahifa Chrome yoki Microsoft Edge brauzerida ochiladi.

Internet talab qilinmaydigan funksiyalar:
- Kontrastni o‘zgartirish
- Matn o‘lchamini o‘zgartirish
- Matnni ovoz chiqarib o‘qish (brauzer/qurilma ovozlariga bog‘liq)
- Matnni sodda ko‘rinishga keltirish (namunaviy, qoidaga asoslangan)
- Muloqot iboralarini tanlash
- Namunaviy test

MUHIM:
Bu hozircha front-end prototip. Unda foydalanuvchi akkauntlari, server, ma’lumotlar bazasi,
haqiqiy avtomatik subtitr yaratish, AI asosida ishonchli soddalashtirish va Android ilovasi
hali mavjud emas. Tanlovda buni tayyor mahsulot emas, ishlaydigan dastlabki prototip sifatida
to‘g‘ri taqdim eting. Keyingi bosqichda server va mobil ilovani qo‘shish mumkin.

Eslatma:
Ovozli o‘qish brauzerdagi Speech Synthesis imkoniyatidan foydalanadi. Uzbek ovozi mavjudligi
kompyuter va brauzerga bog‘liq. Agar o‘zbekcha ovoz bo‘lmasa, qurilmadagi mavjud ovoz tanlanishi mumkin.
